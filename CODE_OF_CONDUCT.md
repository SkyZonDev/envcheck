# Code de conduite

Ce projet suit une règle simple : soyez respectueux.

- Critiquez le code, pas les personnes.
- Accueillez les questions d'onboarding ; c'est le sujet du produit.
- Pas de harcèlement, d'insultes ou de contenu discriminatoire.

Les mainteneurs peuvent refuser un commentaire, un commit ou une PR qui
viole ces règles. Pour un signalement, utilisez les contacts indiqués dans
SECURITY.md plutôt qu'une issue publique.
